# U-Calculator

U-Calculator - это настраиваемое приложение-калькулятор, созданное с использованием React и Redux. Оно позволяет пользователям переключаться между режимами выполнения и конструктора, обеспечивая как использование, так и настройку интерфейса калькулятора.

## Возможности

- **Режим выполнения**: Используйте калькулятор для выполнения базовых арифметических операций.
- **Режим конструктора**: Настраивайте макет калькулятора, перетаскивая элементы.

## Установка

1. Клонируйте репозиторий:

```sh
git clone https://github.com/IlhomAliyev/u-calculator.git
```

2. Перейдите в каталог проекта:

```sh
cd u-calculator
```

3. Установите зависимости:

```sh
yarn
```

## Использование

- **Сервер разработки**: Запустите сервер разработки с горячей перезагрузкой:
  ```sh
  yarn dev
  ```
- **Сборка**: Создайте сборку для продакшена:
  ```sh
  yarn build
  ```
- **Предпросмотр**: Просмотрите сборку для продакшена:
  ```sh
  yarn preview
  ```
